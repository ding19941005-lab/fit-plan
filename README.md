# 健身房减脂增肌本

为 1997 年出生、172cm、起点 78kg、体脂参考 24.1%、无已知伤病的成年初学者编排。沿用原网页结构，并增加完整动作库页，使用胸肩、背部、臀腿三分化，核心分散在三次训练末尾。

例如周一胸肩＋核心、周三背部＋核心、周五臀腿＋核心。训练日间至少隔一天，可按本周空闲时间调整顺序。每个主题每周一次，漏练不补双份。

前四周每个动作两组；第五周起推胸、肩推、下拉、划船、腿举、臀桥、腿弯举三组，其余辅助和核心两组。增肌期主要动作最多四组，辅助和核心仍两组。恢复不足时维持原训练量，器械起始重量由现场轻重量试做确定。

训练日先热身约 10 分钟和轻重量试做，再力量训练，最后快走、单车或椭圆机 10–20 分钟并放松。臀腿日疲劳明显时减少收尾有氧，核心动作保持质量优先。连续两次训练所有正式组都达到次数上限、动作稳定且仍留约两次余力，再加最小一档。

本计划按用户确认的三日分组编排，胸肩和背部各集中在每周一天；分组不代表比全身训练更有效。后续按完成率、力量和恢复调整。

## 本周选动作

训练页先显示“本周选动作”，按类别每项选择一个动作，确认后生成打卡清单。首次带入推荐组合，新的一周默认沿用最近一周选择，并等待再次确认。

- 胸肩日：胸部主动作、肩部主动作、胸部补充、肩部补充、核心。
- 背部日：纵向拉、横向拉、上背与肩后束、背部补充、核心。
- 臀腿日：蹲或腿推、髋伸与臀部、大腿后侧、大腿前侧补充、臀腿补充、核心。

资源文件夹中的 **86 个 GIF 已全部收录**，一份原素材对应一条记录。按实际用途分为力量 57、核心 10、热身 8、心肺 4、组合 5、技术练习 2。

底部“动作库”可按名称、原文件名、器械、部位、用途和学习要求检索。每条素材显示学习要求、动作要点、原文件名和可放入的训练类别；可从动作库加入本周待选清单，再确认应用。

目前 69 项可按类别加入周计划，17 项用于其他用途或示意参考。热身激活动作只允许放入合适的辅助类别；心肺、组合及未完整示范的技术素材不替代三分化主动作。所有 86 项都可查看。

核对中发现部分手册标题与动图版本不同，页面已明确标注，例如史密斯卧推示意、上斜凳胸托划船、髋飞机起始姿势，以及与四足版不对应的肩胛控制素材。未修改原手册或原始资源文件。

改选要点“应用本周选择”才生效。已经开始的当天清单保留原动作，后续尚未开始的训练使用新选择；下周带入最新配置。

## 手机使用与记录

固定使用同一手机浏览器。本地存储仍使用 `jzzj-v1`，保留原体重、腰围、打卡与训练历史。每周选择、已开始的当天动作快照和重量记录均保存在本机。

重量和实际次数按具体动作分别记录：推胸机、哑铃推胸等不会混用重量；改选前后的记录均可导出。完成训练后的动作名称也随报告保存，避免周计划改变后难以复盘。

GIF 仅在展开对应动作示范时加载。首次打开网页、刷新和首次加载动图需要网络，不承诺离线重新打开。
