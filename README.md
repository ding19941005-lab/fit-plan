# 健身房减脂增肌本

为 1997 年出生、172cm、起点 78kg、体脂参考 24.1%、无已知伤病的成年初学者编排。沿用原网页四页结构，使用胸肩、背部、臀腿三分化，核心分散在三次训练末尾。

例如周一胸肩＋核心、周三背部＋核心、周五臀腿＋核心。训练日间至少隔一天，可按本周空闲时间调整顺序。每个主题每周一次，漏练不补双份。

前四周每个动作两组；第五周起推胸、肩推、下拉、划船、腿举、臀桥、腿弯举三组，其余辅助和核心两组。增肌期主要动作最多四组，辅助和核心仍两组。恢复不足时维持原训练量，器械起始重量由现场轻重量试做确定。

训练日先热身约 10 分钟和轻重量试做，再力量训练，最后快走、单车或椭圆机 10–20 分钟并放松。臀腿日疲劳明显时减少收尾有氧，核心动作保持质量优先。连续两次训练所有正式组都达到次数上限、动作稳定且仍留约两次余力，再加最小一档。

本计划按用户确认的三日分组编排，胸肩和背部各集中在每周一天；分组不代表比全身训练更有效。后续按完成率、力量和恢复调整。

## 手机使用与记录

固定使用同一手机浏览器。记录仍保存在原有 `jzzj-v1` 本地存储中；保留体重、腰围、打卡、居家及旧健身房历史。三分化记录使用独立标识 `gym-split-v1`，避免与旧方案混淆。

页面有胸肩、背部、臀腿三个选择按钮和各自周完成状态；默认推荐本周尚未完成的主题，新的一周重新开始。旧方案记录仍可导出，不会错误计入三分化主题完成数。

重量、实际次数和座椅档位在动作下方填写；自动保存并随近期报告一起复制。本计划用到的 16 个 GIF 仅在展开说明后加载。首次打开网页、刷新和首次加载动图需要网络，不承诺离线重新打开。
